# Published CSS and fonts

These are publication outputs from Bedrock's `Publishing.Export.files/1`.
`site.css` comes from its `assets/css/site.css`; `fonts.css` comes from
`assets/css/fonts.css` with rewritten public font URLs; `fonts/` comes from
`priv/static/fonts/`. A new publication replaces these files.

Change the owning stylesheet or font source and republish. Customer application
styles outside this directory are separate sources. A local asset build does
not regenerate these publication files. See `WEBSITE.md` for the full source map.
